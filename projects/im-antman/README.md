# I'm Antman! (Я Энтмен!)

Короткометражный анимационный фильм. Комедия, 12+, около 2 минут.
Две версии: русская и английская. Озвучка, музыка и анимация сгенерированы кодом.

**Сюжет.** Курьер Антон Мурашов из города Муравейск падает в чан с «Регенерином-9000»
и получает суперспособность к регенерации. Он учится с ней жить: порезы заживают
за секунду, парикмахер сходит с ума, а котлеты исчезают тарелками. Потом в городе
появляется Барон Дихлофос, и Энтмен выясняет, что тот, кто отрастает, всегда
переживёт баллончик злодея.

## Файлы

| Файл | Что это |
|---|---|
| `out/I_m_Antman_RU.mp4` | фильм на русском (озвучка + субтитры RU) |
| `out/I_m_Antman_EN.mp4` | фильм на английском (озвучка + субтитры EN) |
| `script.py` | сценарий: сцены и реплики на двух языках |
| `draw.py` | персонажи, фоны, эффекты (PIL) |
| `sound.py` | музыка и звуковые эффекты (numpy) |
| `tts.py` | офлайн-озвучка: RHVoice, запасной вариант — espeak-ng |
| `film.py` | сборка: тайминг, кадры, микширование, MP4 |

## Сборка

```bash
pip install numpy pillow espeakng-loader rhvoice-wrapper rhvoice-wrapper-bin
python film.py all --out out      # или: ru / en
```

Нужен `ffmpeg`.
