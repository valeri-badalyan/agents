# Ottoman Uprising (Hero of Armenia)

A historical strategy game set in 1002 AD, where an Armenian warrior must rescue captured compatriots from Turkish imprisonment.

## Setting

- **Time Period:** 1002 AD
- **Location:** Armenian Highlands and Turkish Territories
- **Historical Context:** Armenian Kingdom of Bagratuni era, Seljuk Turkish invasions

## Story

Armen Vardanyan, a disgraced commander haunted by past failure, embarks on a desperate mission to rescue Armenian captives held in Turkish fortresses. Journeying through enemy territory, he faces the might of the Turkish Empire—from common Khudatin soldiers to the terrifying Emperor Malikhor Chenani.

## Antagonists

| Faction | Role | Description |
|---------|------|-------------|
| Khudatins | Warriors | Common Turkish soldiers |
| Bardouins | Veterans | Elite fighters |
| Lehabibs | Generals | Military commanders |
| Rundik | Special | The hero's former friend turned traitor |
| Malikhor Chenani | Emperor | The final boss |

## Game Features

- **Stealth & Combat:** Multiple combat styles and stealth mechanics
- **Moral Choices:** Decisions that affect the story and multiple endings
- **Character Progression:** Skill trees and attribute system
- **Rich Narrative:** 18 chapters with emotional depth
